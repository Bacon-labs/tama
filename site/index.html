Verity developer toolchain

Tama

Create, build, test, audit, and inspect real Verity smart-contract projects from one CLI.

curl -L https://tama.tools/install.sh | sh
Quickstart Commands Manifest Signature Installer

Quickstart

tama init my-protocol
cd my-protocol
tama doctor
tama check
tama build
tama test
tama audit
tama inspect ERC20Lite selectors

Core Commands

init

Create the ERC20Lite starter project.

build

Run Lean, Verity, solc, bridge generation, and Foundry.

test

Pass through directly to forge test.

audit

Check structure, selectors, storage, coverage, and trust boundaries.

inspect

Read manifests, ABI, selectors, storage, Yul, bytecode, and obligations.

doctor

Diagnose toolchain drift and missing dependencies.
